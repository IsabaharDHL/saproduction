# S.A Production

هذه النسخة تستخدم Firebase حتى تظهر تعديلات لوحة التحكم على جميع الأجهزة.

- الموقع يبدأ من `index.html` ولوحة التحكم من `admin.html`.
- بيانات Firebase العامة وبريد مدير اللوحة يوضعان مرة واحدة في `firebase-config.js`.
- كلمة المرور لا توضع في ملفات الموقع؛ تحفظها Firebase Authentication.
- تغيير كلمة المرور يتم مباشرة من داخل لوحة التحكم ولا يحتاج تنزيل أو رفع ملف جديد.
- زر «حفظ التغييرات ونشرها» يضغط الصور ويحفظها مع النصوص والرقم في Firebase دفعة واحدة.
- تغيير رقم واتساب يحدّث روابط واتساب والباركود معًا بعد الحفظ.
- إن وُجدت تعديلات قديمة محفوظة على الجهاز، يظهر زر لاستيرادها ثم نشرها.

قواعد Firestore يجب نشرها في مشروع Firebase قبل استخدام لوحة التحكم.
