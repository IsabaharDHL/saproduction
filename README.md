# S.A Production

ارفع محتويات هذا المجلد إلى جذر المستودع وفعّل GitHub Pages. الموقع: index.html. لوحة التحكم: admin.html.

كلمة المرور تُسلّم في ملف منفصل لا ترفعه للموقع. ملف اللوحة نفسه مشفّر، ولا توجد فيه كلمة مرور صريحة أو نسخة غير مشفّرة من اللوحة. يتطلب الفتح HTTPS ومتصفحًا حديثًا. التحديث أو «قفل اللوحة» يطلب كلمة المرور مجددًا.

هذا قفل لملف لوحة التحكم، وليس نظام صلاحيات للخادم. الصور والتعديلات تبقى في متصفح الجهاز كما في النسخة الأصلية، ولا تُنشر للزوار أو تُزامن مع أجهزة أخرى. من يملك كلمة المرور يستطيع فك الملف والاحتفاظ بنسخة منه. تغيير كلمة المرور لاحقًا يحتاج إعادة تشفير admin.html ورفع النسخة الجديدة.

عند استبدال نسخة قديمة، احذف ملفات admin.js وملفات PHP وبيانات الدخول القديمة من مجلد النشر. لا تنشر ZIP النسخة السابقة أو ملف الباسوورد الخاص. لا تضع admin.html القديم غير المشفّر في المستودع.

رقم واتساب وروابط التواصل والباركود تُحدّث من نفس القيمة المحفوظة. حفظ الرقم في اللوحة يحدّث الموقع المفتوح في تبويب آخر على نفس المتصفح والدومين؛ لا يغيّر بيانات الأجهزة الأخرى لأن التخزين الحالي محلي.
